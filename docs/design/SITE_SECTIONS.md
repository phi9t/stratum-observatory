# Site sections

The site header links to Models, GPU Hardware, and Networking on every page.
The atlas remains the model index; Qwen3.8, Kimi K3 and DeepSeek V4.1 retain dedicated pages.
Model tabs are Architecture, Training, Serving and Evidence. Compare is removed from navigation,
search and published previews; old Compare bookmarks open Architecture. Its pure calculation
and scene code remain covered as legacy internal behavior, without a public navigation entry.

Hardware and Networking have canonical portable entry points, hardware.html and networking.html.
Their headers describe the shared section and carry no model identity metrics or checkpoint strip.
Networking exposes Workload model because payload estimates depend on routing, parameters or cache.
Links from model pages preserve scenario state, including the workload model and selected hardware.
Old model-page Hardware and Networking hashes redirect to the corresponding shared page.

The page registry supplies builds and verifier routing. Browser journeys cover the public links,
workload changes, reloads, legacy bookmarks, local keyboard tabs and mobile navigation. Existing
model math, evidence acceptance, hardware facts and network formulas are unchanged.
