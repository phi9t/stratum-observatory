## Reference, read in full

- DeepseekV3RMSNorm: float32 square/mean/rsqrt, epsilon 1e-6, cast back, learned gain, no mean subtraction or bias. Block gains have width 7168; latent gains 1536 and 512 (constructor default epsilon matches config).
- DeepseekV3RotaryEmbedding: nonpersistent inverse frequencies, cos/sin caches, concatenated half-channel layout. apply_rotary_pos_emb first reshapes adjacent pairs and transposes pair axes, then rotate_half; positions index the trigonometric cache.
- LinearScaling and DynamicNTK subclasses: alternate disabled rope_scaling.type branches, not this checkpoint.
- Yarn subclass: correction bounds floor/ceil of dim*log(original/(rotations*2*pi))/(2*log(base)); clamp; linear ramp over dim/2. Blend base and factor-divided frequencies. cos/sin amplitude is mscale(factor,mscale)/mscale(factor,mscale_all_dim), exactly 1 here. Attention scale separately multiplies by mscale squared, so it is NOT just 1/sqrt(192). All RoPE buffers nonpersistent.
- DeepseekV3MLP: bias-free gate_proj and up_proj, SiLU on gate, product, down_proj. Dense hidden 18432; each routed expert 2048; shared intermediate 2048*1. Each is token-local.
- MoEGate: flatten [B,S,7168] to [B*S,7168]; fp32 bias-free linear to 256; sigmoid scores. noaux_tc asserts eval. Add correction bias ONLY to scores_for_choice. Group into 8 groups of 32; sum top 2 corrected scores; top 4 groups; mask other groups to -infinity; top 8 experts; gather ORIGINAL unbiased sigmoid scores; sum +1e-20 denominator; normalize; scale 2.5.
- DeepseekV3MoE: gate → flatten → moe_infer → reshape → add shared_experts(identity). moe_infer counts routes, argsorts flattened expert ids, repeats/gathers tokens by idxs//top_k; evaluates each nonempty expert; concatenates, undoes permutation; casts to route-weight dtype; weighted sum over selected experts; casts back. ep_size=1 disables all-to-all branches. Shared expert never enters router logits. Forward has no viable training branch for this checkpoint; do not claim this file trains it.
- DeepseekV3Attention: q_a 7168→1536 → RMSNorm → q_b 1536→24576; reshape [B,128,S,192], split 128 nonpositional +64 rotary. kv_a 7168→576; split 512 latent +64 shared positional key, reshape key [B,1,S,64]. Normalize latent; kv_b 512→32768; reshape [B,128,S,256], split 128 key +128 value. Get RoPE using past+current length; rotate q_pe/k_pe; assemble q and k [B,128,S,192], broadcasting shared k_pe. DynamicCache.update WRITES EXPANDED K and V and RETURNS history [B,128,T,192] and [B,128,T,128]. Dot q*k^T, YaRN-modified scale; add causal/padding mask [B,1,S,T]; fp32 softmax cast back; dropout identity (config 0, eval); probability*V; transpose/merge [B,S,16384]; o_proj →7168. Low-rank query disabled branch q_lora_rank=None is not drawn.
- DeepseekV3FlashAttention2: same projections/rotation; pads V 128→192 BEFORE cache.update; transposes into [B,S,H,D]; casts float32 input back if needed; unpads masked input, fused flash causal attention, repads; slices output to128; merge and o_proj. Cannot output attention matrices. Older flash mask alignment issue is documented upstream. Its padded expanded cache differs from eager and must be labelled separately.
- DeepseekV3DecoderLayer: MoE iff n_routed_experts != None AND layer_idx>=first_k_dense_replace AND layer_idx%moe_layer_freq==0. Here indices 0..2 dense, 3..60 MoE. Norm→attention→residual add→norm→FFN→residual add. All attention architecture identical.
- DeepseekV3PreTrainedModel: initialization/loader infrastructure, no forward. Exclude explicitly.
- DeepseekV3Model: mutually exclusive ids/inputs_embeds; convert legacy cache; position arange starts at cache length; embedding; create causal/padding mask; run61 layers; final RMSNorm. No learned position embedding. Optional hidden/attention output packaging.
- DeepseekV3ForCausalLM: independent bias-free lm_head (tie_word_embeddings=false despite class tied-key metadata), full-position logits cast float32. Optional shifted CE loss excluded from inference scope. Generation trims processed input ids, derives position ids, reorders cache for beams.
- DeepseekV3ForSequenceClassification: last nonpadding position → classification projection; not the checkpoint's architectures, excluded.
- repeat_kv is unused by selected reference attention; no invented GQA repeat.
