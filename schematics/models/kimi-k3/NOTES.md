## Module and forward inventory

- SituAndMul: split joined gate/up on last axis, cast to float32, beta*tanh(gate/beta)*sigmoid(gate), optionally linear_beta*tanh(up/linear_beta), multiply and cast back. Config takes SiTU with beta=4 and linear_beta=25.
- KimiDynamicCache: KDA convolution tuples and recurrent state by absolute layer; full-attention expanded key/value lists, concatenation along sequence. Beam reorder touches both types. get_seq_length queries a full-attention layer. Cache is distinct from the within-forward depth bank.
- KimiRMSNorm: float32 mean square, reciprocal square root with epsilon, cast then gain. Sublayer norms use config 1e-5; MLA latent norms use constructor default 1e-6.
- KimiMLP: bias-free gate_proj and up_proj in parallel; concatenate, SiTU, down_proj. First absolute layer only is dense (33792 intermediate).
- KimiBlockSparseMLP: identical arithmetic with w1/w3/w2 naming; routed width=3584 and intermediate=3072.
- KimiMoEGate: float32 linear from full 7168 stream to 896 logits, sigmoid, add learned correction bias for choice only. Group branch is bypassed with num_expert_group=topk_group=1. Unsorted top-16; gather original scores, normalize with 1e-20, scale=1. Shared experts have no router scores.
- KimiSparseMoeBlock: route BEFORE compression; flatten B*S; down-project to 3584; sort/gather dispatched tokens, run selected experts, unpermute, weighted sum in latent space; RMSNorm then up-project to 7168; add always-on shared MLP from original stream with intermediate=6144. Norm occurs after expert aggregation, not per expert. Remaining 92 layers are MoE.
- KimiMLAAttention: q_a 7168→1536; latent RMSNorm; q_b→96*(128+64), reshape [B,96,S,192], split. kv_a→512+64, split; latent RMSNorm and kv_b→96*(128+128), reshape and split K/V. Shared 64-key channels broadcast across heads and concatenated. Despite the rope field names, assert use_nope and rotary_emb=None: NO text rotation. Expanded keys [B,96,S,192] and values [B,96,S,128] are cached. Scores scale by 192^-1/2, causal mask, softmax, weighted V, merge. Flash backend pads V to query width then slices the result. Full-width sigmoid g_proj gate precedes o_proj.
- KimiDeltaAttention: q/k/v projections each 7168→12288; independent depthwise causal conv(kernel=4,bias=False) + SiLU; reshape [B,S,96,128]. f_a 7168→128, f_b→12288 makes per-key forget logits; b_proj→96 makes update logits. FLA kernel L2-normalizes q/k, computes bounded log decay with A_log and dt_bias, sigmoids beta, then recurrent delta update. State is [B,96,128,128] (reference asks for transposed storage layout); fixed convolution history. Single-token cached mode uses fused recurrence, prefill chunk mode; padding unpacks/packs actual tokens. g_proj is full-rank 7168→12288; per-head RMSNorm (shared gain width 128) times sigmoid(g); flatten, o_proj→7168.
- KimiDecoderLayer: selects KDA by (zero-based index+1) in config list; full attention at listed one-based layers, including adjacent final 92/93. Active attention-residual branch mixes previous completed blocks and live prefix BEFORE input RMSNorm. At index%12==0 snapshot old prefix and reset the additive prefix. Attention output extends/reset prefix; mix again before FFN norm; FFN extends prefix. Returns prefix and bank, not a conventional pair of simple residual adds.
- _apply_attn_res: concatenate bank plus prefix [B*S,N,D]; normalize candidates for scoring; multiply gain and learned projection weights; dot scores; softmax ACROSS DEPTH, weighted sum of UNNORMALIZED candidates. No sequence mixing here.
- KimiLinearModel: embed tokens; build causal/linear masks; empty depth bank; traverse 93 layers; final learned depth aggregation, final RMSNorm. No learned text positions. Forces flash_attention_2.
- KimiLinearForCausalLM: untied, bias-free vocabulary head, optional final-position slice, optional training loss outside page scope.
- KimiPreTrainedModel: initialization/framework class, no inference forward.

## What serving changes

SGLang packs KDA q/k/v/output-gate projections into fused_qkvg_proj, f_a/b into a separate small merged projection; supports covered fused convolution/recurrence/output norm in decode with verified stash consumption and fallback. KDA head sharding uses attention TP, not arbitrary global TP. MLA inherits DeepseekV2AttentionMLA with skip_rope=True, absorbs kv_b into w_kc/w_vc during post_load_weights, and gates the TP-local output immediately before o_proj. Its base implementation is separately pinned before displaying absorbed-cache claims. Latent expert sums must be reduced BEFORE RMSNorm; shared experts stay on original stream and can overlap expert dispatch. Optional merged MoE front computes router and latent projection from the same input; correction bias remains float32. Packed MXFP4 expert weights are handled by an explicit specialized loader, not plain weight concatenation. Serving precomputes gain*projection for depth scoring, fuses aggregation+norm and snapshots, delays prefix adds, and preserves raw bank across pipeline ranks. None of these paths is claimed to have run here.

Important serialization difference: SGLang documents stored A_log as head_dim sized, then narrows to num_heads; publisher constructor allocates num_heads. Logical reference parameter accounting follows the publisher, while serialized total reconciliation remains explicit.

## Vision boundary

The exact checkpoint has a MoonViT3d tower: Conv2d RGB patch embed, learned interpolated spatial positions plus fixed temporal positions; 27 pre-norm vision blocks with bidirectional packed per-media attention and 2D rotary q/k, then final RMSNorm. Temporal mean pooling and 2×2 spatial gathering yield grouped width 4096; PatchMergerMLPV2 bias-free 4096→4096→7168 with GELU and post RMSNorm replaces media placeholders before decoder. Full vision internals, preprocessing, tokenization, losses, sampling and quantized numerical execution are excluded from the clean text reference; the interface is drawn and the separate vision ledger counted. The diagram must never imply text RoPE just because vision uses RoPE.

## Verification decision

Installed Python has torch 2.14.0+cpu and transformers 5.17.0, but no fla. Publisher imports FLA unconditionally and forces flash_attention_2; whole-model numerical parity cannot run on this CPU-only environment. Do not create a substitute full-model fixture. Component fixtures may execute exact pinned CPU-compatible definitions in isolation (AST extraction with no arithmetic replacement); these establish only component parity. FLA naive recurrent/gate definitions are separate upstream evidence for a scalar browser implementation, not proof of fused-kernel equivalence.
